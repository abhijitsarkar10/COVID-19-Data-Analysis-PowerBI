# COVID-19-Data-Analysis-PowerBI
# 🦠 COVID-19 Data Analysis & Power BI Dashboard

## 📊 Project Overview

This project presents an interactive Power BI dashboard created to analyze global COVID-19 data using publicly available WHO data.

The dashboard provides an overview of cumulative cases, cumulative deaths, new cases, and country-level COVID-19 statistics through interactive charts, KPIs, tables, and geographic visualization.

## Project Objectives

- Analyze COVID-19 cases across different countries
- Identify countries with the highest number of reported deaths
- Compare cumulative deaths between countries
- Analyze new COVID-19 cases
- Explore the geographic distribution of COVID-19 cases
- Present global COVID-19 data through an interactive dashboard

## Tools & Technologies

- Power BI
- Microsoft Excel
- Data Analysis
- Data Visualization
- Business Intelligence
- Geographic Data Visualization

## Dashboard Features

### Key Performance Indicators

- Cumulative Cases
- Total Deaths
- New Cases

### Visualizations

- Top 10 countries by COVID-19 deaths
- Top 5 countries by cumulative deaths
- Country-level COVID-19 data table
- Geographic distribution of affected countries
- Interactive country filter

## Analysis

The dashboard allows users to explore:

- Countries with the highest reported COVID-19 deaths
- Differences in cumulative cases between countries
- New cases across countries
- Country-level COVID-19 statistics
- Geographic distribution of reported cases and deaths


This project provided practical experience in building an interactive Power BI dashboard using global public-health data. It helped strengthen skills in data visualization, KPI design, country-level analysis, interactive filtering, and geographic visualization.

## 📚 Data Source

The dataset used in this project is based on publicly available World Health Organization (WHO) COVID-19 data.
